## Getting Started

No build tools or dependencies needed. Just open the file in your browser:

```bash
# Clone the repo
git clone https://github.com/your-username/portfolio.git

# Open in browser
open index.html
```

---

## Customisation

To update the portfolio with new projects or info:

1. Open `index.html` in any text editor
2. Find the section you want to edit (each section has a comment label like `<!-- PROJECTS -->`)
3. Update the content and save
